## 日本服务器购买先定线路：软银、CN2 GIA、三网优化到底差在哪

线路是唯一一项买了之后改不了的东西，配置可以升，线路只能换商家。

**普通国际 BGP** 走公网，回国绕日本本地运营商或者经美国转一圈，晚高峰丢包和延迟抖动都明显。这类线路便宜，适合自娱自乐的博客、开发测试、跑个爬虫。

**CN2 GIA** 是中国电信下一代承载网里优先级最高的那一档，回程走 AS4809 直连国内骨干。以恒创科技的日本节点为例，机房在东京 Equinix TY8，网络用 KDDI、SoftBank、IIJ、NTT 四家运营商做全穿透动态 BGP，回程电信走 CN2 GIA，移动走 CMI 直连，联通走国内骨干，官方标称中国访问延迟 60–120ms，第三方测评本地 Ping 在 60–163ms 之间，丢包不明显。这套组合是目前「回国优化」里性价比较合理的一档。

**IPLC / IEPL 专线** 走的是内网互联，根本不看公网晚高峰的脸色。MKCloud 的沪日专线从上海电信入口走 IPLC 出日本 BGP，走 APG 海缆，端内延迟标称 25–28ms，第三方实测 Ping 稳定在 25ms 上下。做高频操作、抢购、直播推流的，这几十毫秒就是两个体验级别。

**软银、IIJ、NTT 这类日本本地运营商线路**，逻辑和上面几条不一样。它们优化的是日本本土的出口质量，对日本本地网站、日区流媒体、Google 全家桶友好，但回中国不保证优化。这是最容易踩的坑：看到商品名写着「日本软银」就以为回国快，其实是两回事。

## 常见问题

### 日本服务器需要备案吗？

不需要。海外节点包括日本、香港、美国都不走 ICP 备案，开通即用。六六云这类商家也是付款后自动开通，没有备案环节。

### 日本软银线路回国快吗？

不一定。软银优化的是日本本土出口，回中国这一段没有保证。六六云的日本机器就属于这种情况，第三方测评明确指出官方没有宣称优化 CN2，本地测试还有丢包。要回国快，看 CN2 GIA 或者 IPLC 专线，别看运营商名字。

### 流量是双向计费吗？

是。1TB 指的是上传加下载合起来 1TB，超出后按各商家规则处理，通常是暂停或者限速。做同步、备份、传大文件的，按实际用量乘二来估。

### 1TB 流量一个月够用吗？

搭个人博客、企业展示站、日均几千 PV 的量，1TB 一个月根本用不完。跑视频、跑下载、做图床的，1TB 可能一周就见底，这种情况要么升流量档，要么换按带宽计费的独享产品。
